# Read PDF Aloud: PDF Text to Speech & Voice Reader

Read PDF Aloud is a free browser extension that reads PDF files out loud and highlights each sentence as it's read. It reads two-column research papers in the right order, skips headers and page numbers, and picks a voice that matches the language of your document.

- **Install:** [Chrome Web Store](https://chromewebstore.google.com/detail/read-pdf-aloud-pdf-text-t/dpombnoddjohiickoanmelbkcdlemaca?utm_source=github)
- **Website and FAQ:** https://vcoder-studio.github.io/read-pdf-aloud/
- **Free vs PRO:** free for the first 4 pages of any PDF; PRO ($9.99 one-time) reads documents up to 100 pages.
- **Privacy:** your PDF is processed in your browser and never uploaded. [Privacy policy](https://vcoder-studio.github.io/read-pdf-aloud/privacy.html)
